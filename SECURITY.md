# Security Policy

## Supported Versions

Security fixes are provided for the latest version published from the `main` branch.

## Reporting a Vulnerability

Please report security issues privately through GitHub private vulnerability reporting for this repository:

https://github.com/holgerb/ha-life-events-ng/security/advisories/new

If private vulnerability reporting is unavailable, open a minimal public issue that avoids exploit details and request a private contact path.

Do not disclose vulnerability details publicly until a fix is available.
